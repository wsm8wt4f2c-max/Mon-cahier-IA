# Mon-cahier-IA

Mon Cahier AI est un assistant pédagogique intelligent conçu pour les enseignants du primaire.

## Fonctionnalités

- Génération de fiches de préparation avec IA
- Cahier journal
- Évaluations
- Traces écrites
- Scan de canevas par caméra
- OCR
- Export PDF
- Sauvegarde Firebase
- Version Web
- Version Android
- Version iOS

## Technologies

- Flutter
- Firebase
- Node.js
- OpenAI API
- Firebase Storage
- Firestore

## Structure

mobile/ → Application Flutter

backend/ → API Node.js

admin/ → Tableau de bord

docs/ → Documentation
